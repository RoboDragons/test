# Git / GitHub 学習プログラム

RoboDragons向けのGit・GitHub学習カリキュラムです。  
初学者から上級者まで、ステップアップしながら学べる構成になっています。

---

## 📚 学習レベル

| レベル | 対象 | 内容 |
|--------|------|------|
| 🟢 [初級 (Beginner)](./beginner/README.md) | Git未経験〜使い始め | 環境構築、基本コマンド、ブランチ入門 |
| 🟡 [中級 (Intermediate)](./intermediate/README.md) | 基本操作ができる | マージ、リモート操作、PR・Issueの活用 |
| 🔴 [上級 (Advanced)](./advanced/README.md) | チームで開発できる | リベース、Gitフロー、GitHub Actions |

---

## 🗺️ 学習の流れ

```
初級
  ├── 1. Gitの環境構築
  ├── 2. 基本コマンド (add / commit / push / pull)
  └── 3. ブランチ入門 (branch / checkout)

中級
  ├── 1. ブランチのマージ (merge / コンフリクト解消)
  ├── 2. リモート操作 (fetch / pull / push)
  └── 3. GitHubの機能 (Pull Request / Issue / Code Review)

上級
  ├── 1. リベース (rebase / cherry-pick)
  ├── 2. Gitフロー (開発ワークフロー設計)
  └── 3. GitHub Actions (CI/CD の自動化)
```
